# Assets

Every asset the site ships or plans to ship: file, budget, naming, source, licence and status. Code never blocks on an asset (brief §13); missing media render as placeholders. Source files that are not deployed (photos, Blender files, Tripo task links) go in `/art-source`, which is never published.

Status: **in use** · **generated** (built from code) · **planned** · **blocked** (waiting for the owner).
